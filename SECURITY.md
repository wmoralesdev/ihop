# Security policy

## Supported versions

Security fixes are provided for the latest published version of IHOP.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/wmoralesdev/ihop/security/advisories/new)
and include:

- affected IHOP and Node.js versions;
- operating system;
- a minimal reproduction;
- impact and any known mitigations.

Do not include real credentials or sensitive process command lines. You should
receive an initial response within seven days.
